Smart Expense Tracker 💰

A personal finance web application built using HTML, CSS, and JavaScript to track income, expenses, and available balance.

Features

- Track income and expenses
- Calculate available balance automatically
- Categorize expenses
- View transaction history
- Search and filter transactions
- Save transactions in browser storage
- Export transaction data to CSV
- Dark-themed dashboard

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Add transactions to explore the features.

Project Purpose

This project was developed to practice frontend web development, JavaScript functionality, and browser-based data storage.
